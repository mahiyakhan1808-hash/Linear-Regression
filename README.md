🌡️ Celsius to Fahrenheit Prediction Using Linear Regression
📌 Project Overview

This project demonstrates how Linear Regression can be used to predict Fahrenheit temperature from Celsius temperature.

The model is developed using Statsmodels, a Python library commonly used for statistical modeling and analysis. The project focuses on understanding the relationship between Celsius and Fahrenheit and applying a simple linear regression model to make predictions.

🎯 Objective

The main objective of this project is to understand and implement a simple Linear Regression model using Statsmodels.

The project helps demonstrate:

How Linear Regression works
How an independent variable can be used to predict a dependent variable
How to build a regression model using Statsmodels
How to interpret statistical model results
How to use a trained model for prediction
🛠️ Technologies Used
Python
Statsmodels
Pandas
Matplotlib
Jupyter Notebook
🧠 Machine Learning Concept

This project uses Simple Linear Regression, where:

Celsius is the independent variable.
Fahrenheit is the dependent variable.

The model learns the linear relationship between the two variables and uses it to predict Fahrenheit values from Celsius values.

📊 Model Analysis

Using Statsmodels, the regression model provides statistical information that can be used to understand model performance and the relationship between the variables.

Important outputs include:

R-squared
Regression coefficients
P-values
Standard errors
Confidence intervals
Statistical significance
📈 Visualization

The relationship between Celsius and Fahrenheit can be visualized using a scatter plot and a regression line.

This makes it easier to understand how the predicted values relate to the actual temperature relationship.
